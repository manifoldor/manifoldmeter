概述

Manifold Meter 是一个本地优先的 Chrome 扩展，用于向用户展示其 Codex 用量以及用户单独连接的 Claude 订阅额度和重置时间。本政策说明扩展处理哪些数据、为何处理、 如何存储以及用户如何控制这些数据。

Manifold Meter 对从 Chrome、ChatGPT 和 Claude 获得的信息的使用遵守 Chrome Web Store 用户数据政策，包括 Limited Use（有限使用）要求。 数据仅用于提供和改进扩展的单一用途，不会用于广告、画像或销售。

处理的数据

  • Codex 用量元数据：5小时额度、本周额度、其他可用窗口的已用/剩余比例、重置时间、可用重置和限额状态。
  • 账户服务元数据：套餐类型、可选的剩余积分及相关限额状态。
  • 认证信息：用于向 chatgpt.com 请求上述数据的短期访问令牌；浏览器也可能向同源请求附加现有 ChatGPT Cookie。
  • 账户标识：扩展会提取当前 ChatGPT 账户 ID，用于将用量请求路由到正确账户。
  • 会话响应可能包含姓名、邮箱等其他账户属性；扩展不提取、使用或保存这些属性。
  • 如果用户另行连接 Claude：从 claude.ai 读取组织标识、组织名称、所选组织账户成员信息中的套餐类别、5 小时和周额度百分比及重置时间。账户响应中的姓名、邮箱等字段不提取或保存。扩展使用浏览器现有会话，不提取或保存 Claude Cookie。

显著披露与同意

首次安装后，扩展会在连接页面中说明所处理的数据及用途。在用户点击 “同意并连接 Codex 数据”之前，扩展不会读取 ChatGPT 会话、账户标识或 Codex 用量，也不会启动相关自动同步。

Claude 连接单独征求同意并申请 claude.ai 站点权限。用户未启用时，扩展不会请求 claude.ai 或读取 Claude 用量。

数据用途与传输

  • 数据仅用于显示用户已连接服务的剩余额度、重置时间、同步状态和工具栏徽标。
  • Codex 网络请求发送至 https://chatgpt.com，用于取得用户请求显示的用量信息。
  • 启用 Claude 后，额外向 https://claude.ai 请求组织列表和用量信息。
  • 数据不会发送到 Manifold Meter 开发者控制的服务器。
  • 数据不会被出售、用于个性化广告、信用评估或其他无关用途。
  • 除法律要求或保护用户安全所必需的情形外，不向其他第三方披露数据，也不允许人工读取。

存储与保留

  • 标准化后的额度快照保存在 chrome.storage.local，只存在于当前设备。
  • 访问令牌和账户 ID 仅短暂保存在 Chrome 的内存会话存储 chrome.storage.session 中。
  • 浏览器重启、扩展重新加载、更新或停用时，上述会话数据会被清除。
  • 额度快照会被后续快照覆盖，并在卸载扩展时由 Chrome 清除。
  • Claude 组织标识、名称和额度快照仅存于本地；断开 Claude 时清除这些数据和站点权限。

用户选择

用户可以随时停用或卸载扩展，以停止所有数据处理。用户也可以退出 ChatGPT，使后续用量请求无法通过认证。用户可在连接页分别断开 Codex 或 Claude，并清除对应本地数据。

安全

扩展使用 HTTPS 与 chatgpt.com 或 claude.ai 通信，不加载远程可执行代码，并使用 Chrome 扩展存储隔离机制保护本地状态。

政策变更与联系方式

如果数据处理方式发生实质变化，本政策和 Chrome Web Store 数据披露将同步更新。问题可发送至 linyishan@gmail.com。

Privacy Policy — English

Updated: October 25, 2026

Manifold Meter is a local-first Chrome extension that displays a user's Codex usage and, when separately connected, Claude subscription allowances and reset times.

Manifold Meter's use of information received from Chrome, ChatGPT, and Claude complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide and improve the extension's single purpose and is never used for advertising, profiling, or sale.

Data handled

  • Codex usage metadata, including available usage percentages, allowance windows, reset times, available reset credits, and limit status.
  • Service metadata, including plan type and optional service credit balance.
  • A short-lived access token and ChatGPT account ID used to request this data for the correct account.
  • Session responses may contain other account attributes; the extension does not extract, use, or store names or email addresses.
  • If the user separately connects Claude, the extension reads the organization ID and name, the plan category from the selected organization’s account membership, usage percentages, and reset times from claude.ai using the existing browser session. It does not extract or store names, email addresses, or Claude cookies.

Prominent disclosure and consent

After installation, the connection screen explains the data handled and its purpose. The extension does not read ChatGPT session data, the account identifier, or Codex usage, and does not begin related automatic syncing, until the user clicks “Agree and connect Codex data.”

Claude requires a separate consent action and optional claude.ai host permission. No Claude request is made before that action.

Use, sharing, and storage

  • Data is used only to display the connected services' allowances, reset times, and synchronization status.
  • Codex requests are sent to https://chatgpt.com. No data is sent to servers controlled by the developer.
  • After optional Claude connection, organization and usage requests are also sent to https://claude.ai.
  • Data is not sold, used for personalized advertising, or disclosed for unrelated purposes.
  • Normalized quota snapshots are stored locally on the device in chrome.storage.local.
  • The access token and account ID are held only in in-memory chrome.storage.session and are cleared when Chrome restarts or the extension is reloaded, updated, or disabled.
  • Uninstalling the extension removes its locally stored data.
  • Disconnecting Codex removes its local usage data and session credentials. Disconnecting Claude removes its local organization and usage data and revokes its host permission.

Your choices and contact

You may disconnect Codex or Claude, disable, or uninstall the extension at any time. For privacy or support questions, contact linyishan@gmail.com.

Material changes to these practices will be reflected in this policy and in the Chrome Web Store disclosures.

Manifold Meter is independent software and is not affiliated with or endorsed by OpenAI or Anthropic.
