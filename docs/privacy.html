隐私政策

Manifold Meter · 生效日期：2026 年 7 月 3 日

English

概述

Manifold Meter 是一个本地优先的 Chrome 扩展，用于向用户展示其 Codex 用量、额度和重置时间。本政策说明扩展处理哪些数据、为何处理、 如何存储以及用户如何控制这些数据。

Manifold Meter 对从 Chrome 和 ChatGPT 获得的信息的使用遵守 Chrome Web Store 用户数据政策，包括 Limited Use（有限使用）要求。 数据仅用于提供和改进扩展的单一用途，不会用于广告、画像或销售。

处理的数据

  • Codex 用量元数据：当前窗口与每周窗口的已用/剩余比例、重置时间和限额状态。
  • 账户服务元数据：套餐类型、可选的 Credits 余额及相关限额状态。
  • 认证信息：用于向 chatgpt.com 请求上述数据的短期访问令牌；浏览器也可能向同源请求附加现有 ChatGPT Cookie。
  • 会话响应可能包含账户属性，但扩展只提取访问令牌，不使用或保存姓名、邮箱、账户 ID 等属性。

数据用途与传输

  • 数据仅用于显示 Codex 剩余额度、重置时间、同步状态和工具栏徽标。
  • 网络请求仅发送至 https://chatgpt.com，用于取得用户请求显示的用量信息。
  • 数据不会发送到 Manifold Meter 开发者控制的服务器。
  • 数据不会被出售、用于个性化广告、信用评估或其他无关用途。
  • 除法律要求或保护用户安全所必需的情形外，不向其他第三方披露数据，也不允许人工读取。

存储与保留

  • 标准化后的额度快照保存在 chrome.storage.local，只存在于当前设备。
  • 访问令牌仅短暂保存在 Chrome 的内存会话存储 chrome.storage.session 中。
  • 浏览器重启、扩展重新加载、更新或停用时，会话令牌会被清除。
  • 额度快照会被后续快照覆盖，并在卸载扩展时由 Chrome 清除。

用户选择

用户可以随时停用或卸载扩展，以停止所有数据处理。用户也可以退出 ChatGPT，使后续用量请求无法通过认证。

安全

扩展使用 HTTPS 与 chatgpt.com 通信，不加载远程可执行代码，并使用 Chrome 扩展存储隔离机制保护本地状态。

政策变更与联系方式

如果数据处理方式发生实质变化，本政策和 Chrome Web Store 数据披露将同步更新。问题可发送至 linyishan@gmail.com。

Privacy Policy — English

Effective date: July 3, 2026

Manifold Meter is a local-first Chrome extension that displays a user's Codex usage, allowances, and reset times.

Manifold Meter's use of information received from Chrome and ChatGPT complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide and improve the extension's single purpose and is never used for advertising, profiling, or sale.

Data handled

  • Codex quota metadata, including usage percentages, reset times, and limit status.
  • Service metadata, including plan type and optional service credit balance.
  • A short-lived access token used to request this data from chatgpt.com.
  • Session responses may contain account attributes; the extension extracts only the access token and does not use or store names, email addresses, or account IDs.

Use, sharing, and storage

  • Data is used only to display Codex availability and synchronization status.
  • Requests are sent only to https://chatgpt.com. No data is sent to servers controlled by the developer.
  • Data is not sold, used for personalized advertising, or disclosed for unrelated purposes.
  • Normalized quota snapshots are stored locally on the device in chrome.storage.local.
  • The access token is held only in in-memory chrome.storage.session and is cleared when Chrome restarts or the extension is reloaded, updated, or disabled.
  • Uninstalling the extension removes its locally stored data.

Your choices and contact

You may disable or uninstall the extension at any time. For privacy or support questions, contact linyishan@gmail.com.

Material changes to these practices will be reflected in this policy and in the Chrome Web Store disclosures.

Manifold Meter is independent software and is not affiliated with or endorsed by OpenAI.
