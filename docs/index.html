Manifold Meter

Many models. One meter.

把 AI 用量放到余光里

Manifold Meter 是本地优先的 Chrome 扩展，在工具栏和副屏显示已连接服务的 5 小时额度、本周额度、重置时间和同步状态。Codex 还可展示剩余积分与可用重置； Claude 订阅额度可单独连接。在弹窗选择“双服务”，即可同时查看两项额度： 副屏左右并排，弹窗上下显示，各自保留套餐类别与更新状态。

两个服务分别授权。扩展沿用浏览器中已有的 ChatGPT 或 Claude 登录状态， 不需要 Manifold 账户，也不会将用量数据上传到开发者服务器。

数据说明：连接 Codex 前会说明并征得同意，随后从 chatgpt.com 读取短期认证信息、 账户标识和用量元数据。Claude 需另行同意并授予 claude.ai 站点权限，随后读取组织标识、 订阅额度和重置时间。额度快照仅存于本机。
