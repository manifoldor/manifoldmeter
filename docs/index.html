Manifold Meter

Many models. One meter.

把 Codex 用量放到余光里

Manifold Meter 是本地优先的 Chrome 扩展，用于显示 Codex 5小时额度、本周额度、重置时间、剩余积分和可用重置。

扩展沿用浏览器中现有的 ChatGPT 登录状态，不需要 Manifold 账户，也不会将用量数据上传到开发者服务器。

数据说明：首次连接前，扩展会先征得你的明确同意。连接后仅处理来自 chatgpt.com 的短期认证信息、账户标识和 Codex 用量/剩余积分元数据，用于在本机 显示额度与同步状态；不会发送到开发者控制的服务器。
