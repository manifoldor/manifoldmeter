Manifold Meter

Many models. One meter.

把 Codex 用量放到余光里

Manifold Meter 是本地优先的 Chrome 扩展，用于显示当前 Codex 用量窗口、每周额度、重置时间和可用 Credits。

扩展沿用浏览器中现有的 ChatGPT 登录状态，不需要 Manifold 账户，也不会将用量数据上传到开发者服务器。
