# Manifold Meter 2.0.5 更新说明

- 工具栏弹窗移除手动刷新按钮；用户同意连接后，打开时自动同步，并由后台持续协调更新
- 首次安装流程调整为“阅读数据说明并同意连接 → 同步成功 → 打开副屏仪表盘”
- 在首次读取 ChatGPT 会话或 Codex 用量前增加显著数据披露和明确同意；后台、弹窗、副屏及页面脚本统一遵守该状态
- 引导页会根据本地同步状态自动切换主操作，并提供明确的连接失败恢复提示
- 将方案 1 的背景、文字、苔绿、琥珀、字重和进度样式统一到弹窗、引导页、官网与商店素材
- PLUS 演示保留 5小时额度和本周额度，PRO 演示仅显示本周额度
- 统一演示重置日期、自动重试文案和商店自动同步说明
- 隐私政策补齐账户 ID 会话存储、显著披露和同意说明，并改善手机页面导航和键盘焦点
